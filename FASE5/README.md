# 🫀 Sobre o CardioIA

O CardioIA é um projeto acadêmico voltado à aplicação de Inteligência Artificial em um cenário relacionado à saúde cardiovascular.

Nas diferentes fases, o projeto evolui desde a classificação de informações de ECG até a criação de uma camada conversacional e de automação.

> **Aviso:** o CardioIA é um protótipo acadêmico. Os dados utilizados nas atividades são simulados e o sistema não substitui avaliação, diagnóstico ou decisão de profissionais de saúde.
